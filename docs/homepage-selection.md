# Homepage product selection

Both languages use the same four positions, in ascending price order:

1. Entry-level solid wood board, approximately EUR 50-150.
2. Core end-grain board, approximately EUR 200-300.
3. Premium 3D board, approximately EUR 400-600.
4. Custom-made XXL board (listing 4484195050), currently from EUR 1,199.

The fourth position is reserved for the custom XXL offer. Do not replace it
with a stock board. When a piece in positions 1-3 sells, choose an available
replacement in the same price tier and update both languages together.
Do not change prices to meet a tier. If no suitable replacement exists,
request an owner decision.

Run `node --test tests/homepage-price-ladder.test.cjs` after selection changes.
