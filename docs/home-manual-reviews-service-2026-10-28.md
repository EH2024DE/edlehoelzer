# Homepage: manual reviews, consistent crop and service

Supersedes the automatic review-rail experiment. Preview only; no publication.

- Removed the complete play/previous/next controls from the reviews section.
- Deleted review animation scheduling, automatic scroll, node rotation and
  playback state. Native touch/trackpad scrolling remains; arrow keys and the
  full-review modal remain available for keyboard users.
- 3D homepage photo uses a scoped 1.32x CSS display crop, translated down 8%,
  keeping the board complete and aligning its base/table area with adjacent
  images. Source photos and other product views are unchanged.
- Original homepage used both 'Aus gutem Holz. Fuer echten Alltag.' and
  'Holz mit Geschichte. Fuer deinen Alltag.' New separate messages are
  'Gutes Holz. Persoenlicher Service.' and 'Holz mit Geschichte. Zum Weitergeben.'
- Added a fourth proof point: available wood/variant choices, personal advice,
  the buyer's final selection and mockup approval before engraving. DE/EN match.
- Responsive proof grid uses four columns, two at intermediate widths, one on mobile.

Verification: 164 Node tests passed. DE/EN at 375, 430, 768, 1024 and 1440px
checked for stationary reviews, stable record order, manual keyboard scrolling,
native mobile touch swipe, full-text modal, service copy, image transform and
no document overflow. Desktop/mobile screenshots inspected.
